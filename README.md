# ОПЕРА — приглашение на музыкальный вечер

Статический адаптивный сайт в стиле печатной музыкальной афиши. Нет голосования, формы регистрации, аналитики и серверных запросов. Все шрифты системные; изображения, CSS и JS хранятся здесь, без внешних CDN.

## Где менять данные
Откройте `event-config.js`:
- `title` — название вечера;
- `venue`, `address`, `mapUrl` — площадка и карта;
- `date`, `gathering`, `musicStart` — дата, сбор и начало музыки;
- `artists` — список строк либо объектов `{name: 'Имя', description: 'Короткое описание'}`;
- `rsvpUrl` — ссылка подтверждения в Telegram (или другая HTTPS-ссылка). Пока пусто — кнопки честно показывают «ссылка скоро»;
- `estimatePerPerson`, `durationHours` — предварительный ориентир участия и длительность;
- `eventNote`, `priceNote` — оговорки.

Все неизвестные значения явно отмечены. Живая музыка и состав не объявлены подтверждёнными. Ориентир 3500 ₽ с человека за 8 часов задан организатором и отделён от сценарного калькулятора аренды. Тарифы и условия из объявления проверены 15.11.2026, на декабрь требуют подтверждения. Калькулятор учитывает уборку и ограничения минимальной аренды, еду, напитки и прочие расходы. Нули еды/напитков не означают, что они бесплатны.

`opera.css` — оформление, `opera.js` — подстановка данных и расчёт, `index.html` — содержание и оригинальная SVG-иллюстрация ударных. `pizza.html` — сохранённый калькулятор пиццы.
